# Домашка по фото — Telegram-бот

Бот принимает школьные задания по фото и возвращает решение по шагам с оформлением для тетради. Работает с разными предметами, если текст на снимке читаем.

## Подключение
1. Создай бота через [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Получи API-ключ Gemini в [Google AI Studio](https://aistudio.google.com/apikey).
3. На хостинге добавь секреты (Environment variables / Secrets):
   - `TELEGRAM_BOT_TOKEN` — токен Telegram.
   - `GEMINI_API_KEY` — ключ Gemini.
   - необязательно `GEMINI_MODEL` — модель, по умолчанию `gemini-2.5-flash`.
4. Команда запуска: `python bot.py`. Нужен постоянно работающий Python-процесс с исходящими HTTPS-запросами.

## Локальный запуск
Нужен Python 3.11+:
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="ваш-токен"
export GEMINI_API_KEY="ваш-ключ"
python bot.py
```

## Важно
GitHub хранит код, но сам по себе не запускает polling-бота постоянно. Нужен хостинг с постоянным процессом и секретами. GitHub Actions с периодическим запуском не подходит для надёжного непрерывного приёма сообщений. Бесплатные хостинги и ИИ имеют ограничения по доступности, времени работы и квотам; безлимитность не гарантируется.

Не добавляй токены в репозиторий. Если токен случайно опубликован, отзови его в BotFather и создай новый. Фото не сохраняются в базу данных, но отправляются поставщику ИИ для обработки. Перепроверяй ответы: модель может ошибаться, особенно при рукописном или размытом тексте.
