# Домашка по фото — Telegram-бот

Бот принимает фотографию школьного задания и возвращает решение по шагам с оформлением для тетради. Поддерживает разные предметы, если снимок читаемый.

## Что используется

- Python 3.12
- Telegram Bot API
- Groq API с моделью по умолчанию `qwen/qwen3.8-27b`
- Docker для запуска на хостинге

## Запуск на Render

1. Открой [Render](https://render.com/) и войди или создай аккаунт.
2. Нажми **New +** → **Blueprint**.
3. Подключи GitHub, если он ещё не подключён, и выбери репозиторий `Dima911-png/atlas-world`.
4. Render прочитает `render.yaml` и предложит создать сервис `homework-photo-telegram-bot`.
5. В настройках переменных окружения укажи:
   - `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather.
   - `GROQ_API_KEY` — ключ Groq.
   - `GROQ_MODEL` — необязательно; по умолчанию `qwen/qwen3.8-27b`.
6. Создай сервис и дождись завершения деплоя. Проверь логи: процесс должен оставаться запущенным без ошибок.

**Важно:** секреты нельзя публиковать в коде или коммитах. Если Render не предложит значения для переменных `sync: false`, добавь их вручную в Environment.

## Локальный запуск

Требуется Python 3.12+:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="ваш-токен"
export GROQ_API_KEY="ваш-ключ"
python bot.py
```

## Проверка

GitHub хранит код, но сам по себе не запускает бота постоянно. GitHub Actions проверяет синтаксис и доступность API по ручному запуску; для постоянного приёма сообщений нужен работающий хостинг.

Бесплатный тариф хостинга для постоянно работающего worker может быть недоступен; перед созданием сервиса проверь актуальную цену Render. Безлимитность хостинга и ИИ не гарантируется.

Фотографии отправляются поставщику ИИ для обработки. Не отправляй чувствительные документы. Проверяй решения: модель может ошибаться, особенно при рукописном или размытом тексте.
